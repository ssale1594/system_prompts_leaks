# جامع تغريدات النرجسية — @Fisalahs

## التثبيت
```bash
pip install -r requirements.txt
```

## التشغيل
```bash
python scraper.py
```

سيطلب منك إيميل وكلمة مرور حساب تويتر الخاص بك (ليس حساب فيصل).

## المخرجات (مجلد output/)
- `tweets.json` — البيانات الخام
- `كتيب_النرجسية.md` — ملف Markdown منسق (افضل خيار للعربية)
- `tweets.pdf` — PDF (يحتاج تعديل للعربية الصحيحة)
